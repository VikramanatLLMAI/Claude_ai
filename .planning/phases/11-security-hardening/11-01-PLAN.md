<task type="auto">
  <name>Task 1: Create rate limiter module and origin validator</name>
  <files>lib/rate-limiter.ts, lib/origin-validator.ts</files>
  <action>
Create `lib/rate-limiter.ts` with:

1. A `RateLimitEntry` interface with `timestamps: number[]`
2. A `Map<string, RateLimitEntry>` store for tracking requests
3. Periodic cleanup via `setInterval` every 60 seconds -- iterate the Map, filter expired timestamps, delete empty entries. Use 15 minutes (largest window) as the max expiry check.
4. `RateLimitConfig` interface: `{ maxRequests: number; windowMs: number }`
5. `RateLimitResult` interface: `{ allowed: boolean; retryAfterSeconds: number; remaining: number }`
6. `checkRateLimit(key: string, config: RateLimitConfig): RateLimitResult` function:
   - Get or create entry from store
   - Filter timestamps to only those within windowMs
   - If count >= maxRequests, calculate retryAfterSeconds from oldest timestamp in window
   - Otherwise push current timestamp, update store, return allowed=true with remaining count
7. `rateLimitResponse(retryAfterSeconds: number): NextResponse` helper:
   - Returns 429 JSON response with `{ error: "Too many requests. Please try again in X seconds." }`
   - Sets `Retry-After` header to retryAfterSeconds string
8. `RATE_LIMITS` const object with three tiers:
   - `auth: { maxRequests: 5, windowMs: 15 * 60 * 1000 }` (5 per 15 minutes)
   - `api: { maxRequests: 60, windowMs: 60 * 1000 }` (60 per minute)
   - `chat: { maxRequests: 10, windowMs: 60 * 1000 }` (10 per minute)

Create `lib/origin-validator.ts` with:

1. `validateOrigin(req: NextRequest): boolean` function:
   - If method is GET, HEAD, or OPTIONS, return true (safe methods)
   - Get Origin header from request
   - If Origin is absent, return true (same-origin requests may not include it; Bearer token auth is CSRF-immune)
   - Build allowed origins list: `http://localhost:3000` + `https://${ROOT_DOMAIN}` (from env)
   - Allow any subdomain of ROOT_DOMAIN: check if origin matches `https://*.${rootDomain}` pattern
   - Return true if origin is in allowed list, false otherwise
2. `originDeniedResponse(): NextResponse` helper returning 403 with `{ error: "Origin not allowed" }`

Import `NextRequest` and `NextResponse` from `next/server` in both files.
  </action>
  <verify>
    <automated>npx tsc --noEmit lib/rate-limiter.ts lib/origin-validator.ts 2>&1 | head -20</automated>
  </verify>
  <done>Both files compile without errors. checkRateLimit correctly counts sliding window requests, rateLimitResponse returns 429 with Retry-After header, validateOrigin checks Origin against allowed list.</done>
</task>

<task type="auto">
  <name>Task 2: Configure security headers in next.config.ts</name>
  <files>next.config.ts</files>
  <action>
Update `next.config.ts` to add the `headers()` async function to the existing config (keep `output: "standalone"`).

Add a `securityHeaders` array with these headers:
1. `X-Frame-Options: DENY`
2. `X-Content-Type-Options: nosniff`
3. `Referrer-Policy: strict-origin-when-cross-origin`
4. `Permissions-Policy: camera=(), microphone=(), geolocation=()`
5. `Strict-Transport-Security: max-age=31536000; includeSubDomains` (apply unconditionally -- browsers ignore on HTTP)
6. `Content-Security-Policy-Report-Only` with these directives joined by "; ":
   - `default-src 'self'`
   - `script-src 'self' 'unsafe-eval' 'unsafe-inline' https://*.codesandbox.io` (Sandpack needs eval + inline for code execution)
   - `style-src 'self' 'unsafe-inline'` (KaTeX + Mermaid use inline styles)
   - `img-src 'self' data: blob:` (Mermaid SVG data URIs, artifact previews)
   - `font-src 'self' data:` (KaTeX fonts as data URIs)
   - `connect-src 'self' https://*.codesandbox.io https://api.anthropic.com` (Sandpack bundler + Anthropic API for user API key mode)
   - `frame-src 'self' blob: https://*.codesandbox.io` (Sandpack iframes, HTML artifact srcDoc)
   - `worker-src 'self' blob:` (Sandpack web workers)

Apply headers to `source: '/:path*'` to match all routes.

Keep the config typed as `NextConfig` from "next".
  </action>
  <verify>
    <automated>npx tsc --noEmit next.config.ts 2>&1 | head -10</automated>
  </verify>
  <done>next.config.ts compiles with security headers. All 6 standard headers + CSP-Report-Only are configured. CSP allows Sandpack (blob: frames, codesandbox.io, unsafe-eval), Mermaid (inline styles, data: images), and KaTeX (data: fonts, inline styles).</done>
