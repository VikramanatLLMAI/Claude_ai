     - `GET` -- requireOrgAdmin -> get role by roleId (verify belongs to org) -> return { allowedModels: string[], roleName: string }
     - `PATCH` -- requireOrgAdmin -> validate body ({ allowedModels: string[] }) -> verify at least one model is in the list (minimum model requirement per CONTEXT.md) -> verify all model IDs exist in Model Registry (call getModelsByIds and check count matches) -> update Role.allowedModels -> audit log (action: 'role.models.updated', metadata: { roleId, roleName, allowedModels }) -> return updated role

     - Zod schema: `{ allowedModels: z.array(z.string()).min(1, 'At least one model required') }`

  3. Create `app/api/org/[slug]/admin/roles/[roleId]/settings/route.ts`:
     - `GET` -- requireOrgAdmin -> get role by roleId -> return { customInstructionsEnabled, personalMcpEnabled, personalMcpMaxCount }
     - `PATCH` -- requireOrgAdmin -> validate body -> update role fields -> audit log (action: 'role.settings.updated') -> return updated settings
     - Accepted fields: `customInstructionsEnabled` (boolean), `personalMcpEnabled` (boolean), `personalMcpMaxCount` (integer, min 0, max 20)
     - When `personalMcpEnabled` is toggled ON, `personalMcpMaxCount` defaults to 3 if not provided

  4. Create `components/admin/role-model-assignment.tsx` -- model assignment UI per MODL-07 and CONTEXT.md:
     - Fetch available models from `GET /api/admin/models?status=ACTIVE` (all active models from registry)
     - Group models by `generationGroup`: "Claude 4.6", "Claude 4.5", "Claude 4"
     - Each group has a group-level checkbox with 3 states:
       - Checked: all models in group are selected
       - Unchecked: no models in group are selected
       - Indeterminate (mixed): some models in group are selected
     - Clicking group checkbox toggles all models in that group
     - Each model within a group has an individual checkbox
     - Display model info next to each checkbox: display name, model ID (small monospace text)
     - Props: `roleId: string`, `allowedModels: string[]`, `onSave: (modelIds: string[]) => Promise<void>`
     - Save button: calls onSave with current selection. Disabled if no models selected.
     - For the mixed-state checkbox, install `@radix-ui/react-checkbox` if not already installed, or use the shadcn checkbox component. The indeterminate state is set via `checked="indeterminate"` prop.
     - Run `npx shadcn@latest add checkbox` if the checkbox component doesn't exist at `components/ui/checkbox.tsx`

  5. Create `app/org/[slug]/admin/roles/page.tsx` -- role settings management page:
     - Fetch all roles from GET /api/org/[slug]/admin/roles
     - For each role, show a card/section with:
       a. Role name + description (read-only for Phase 3 -- editing is Phase 4)
       b. **Model Assignment** section with RoleModelAssignment component
       c. **Custom Instructions** section: Switch toggle for `customInstructionsEnabled`. When enabled, shows "Users in this role can write custom instructions (max 200 tokens)". When disabled, shows "Custom instructions disabled for this role".
       d. **Personal MCP Servers** section: Switch toggle for `personalMcpEnabled`. When enabled, shows a number input for `personalMcpMaxCount` (pre-fills with 3 per CONTEXT.md). When disabled, MCP settings section is hidden for users in this role.
     - Save buttons per section (or a single save per role card)
     - Loading skeleton while fetching
