Modify `components/admin/mcp-assignment-panel.tsx` to add the following:

1. **Edit Dialog:**
   - Add state: `editingConnection: OrgMcpConnection | null` and `showEditDialog: boolean`
   - Create an Edit dialog (reuse the same form structure as the Add dialog) pre-filled with the connection's current values
   - "Edit" button (Pencil icon from lucide-react) added to each connection card's action buttons
   - On submit, call PATCH `/api/org/${orgSlug}/admin/mcp/connections/${connection.id}` with updated fields
   - On success: `toast.success("MCP connection updated")`, close dialog, refresh list
   - On error: `toast.error("Failed to update connection: " + errorMessage)`

2. **Replace native confirm() with ConfirmationDialog:**
   - Add state: `deletingConnectionId: string | null`
   - Import `ConfirmationDialog` from `@/components/ui/confirmation-dialog`
   - When delete button clicked, set `deletingConnectionId` to the connection ID instead of calling `window.confirm()`
   - Render `<ConfirmationDialog>` with:
     - title: "Delete MCP Connection"
     - description: `Are you sure you want to delete "${connectionName}"? This action cannot be undone.`
     - confirmLabel: "Delete"
     - variant: "destructive"
     - onConfirm: execute the delete API call
     - loading: true while delete is in progress

3. **Toast notifications:**
   - Import `toast` from `@/components/ui/toast`
   - Add Server success: `toast.success("MCP server added successfully")`
   - Add Server error: `toast.error("Failed to add server: " + message)`
   - Delete success: `toast.success("MCP connection deleted")`
   - Test connection success: `toast.success("Connection test passed")`
   - Test connection failure: `toast.error("Connection test failed: " + message)`

4. **Loading spinner during Add/Edit Server submission:**
   - Add `submitting: boolean` state
   - Set true before API call, false after
   - Disable submit button and show Loader2 spinner icon during submission

5. **API Key field type="password":**
   - Change the API Key input field's type from "text" to "password" so credentials are masked

6. **"Discover tools" button tooltip:**
   - Import Tooltip components from `@/components/ui/tooltip`
   - Wrap the disabled "Discover tools" button in a Tooltip
   - Show "Test connection first to discover available tools" when status is not "connected"

7. **Color-coded connection status dots:**
   - Replace text-only status badge with colored dot + text:
     - `connected`: green dot (`bg-green-500`) + "Connected" text
     - `error`: red dot (`bg-red-500`) + "Error" text
     - `disconnected`: gray dot (`bg-gray-400`) + "Disconnected" text
   - Use a small `w-2 h-2 rounded-full` div for the dot

8. **Action button tooltips:**
   - Wrap each icon-only action button (Test, Discover, Edit, Delete) in Tooltip with descriptive label
   - Wrap the entire action buttons area in `<TooltipProvider>`

9. **Replace native select with styled dropdown for role assignment:**
   - Replace the `<select>` element for role-specific assignment with a custom styled dropdown
   - Use the existing `DropdownMenu` component from `@/components/ui/dropdown-menu` OR build a simple styled select using a Button + popover pattern
   - Style consistently with the rest of the form (border, rounded corners, text size)
   - Keep the same option list (roles passed as props)
