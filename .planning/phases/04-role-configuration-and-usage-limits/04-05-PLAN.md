  <name>Task 1: Profile and session API endpoints</name>
  <files>app/api/org/[slug]/profile/route.ts, app/api/org/[slug]/sessions/route.ts, app/api/org/[slug]/sessions/[sessionId]/route.ts, app/api/org/[slug]/admin/users/[userId]/force-logout/route.ts</files>
  <action>
  **Part A: Profile API**

  Create `app/api/org/[slug]/profile/route.ts`:

  GET handler:
  - `requireOrgAuth()` (not admin-only -- regular users)
  - Return: `{ name, email, avatarBase64, roleName, roleId, joinedAt }`
  - Email and role are read-only info for display (UPRF-03, UPRF-04)

  PATCH handler:
  - `requireOrgAuth()`
  - Zod validation: `{ name?: string (2-100 chars), avatarBase64?: string | null }`
  - If name provided: update `user.name` via raw prisma (User is not org-scoped)
  - If avatarBase64 provided: validate it starts with `data:image/` prefix, validate size (Base64 decoded < 200KB), update `user.avatarBase64`
  - If avatarBase64 is null: clear the avatar
  - Cannot update email or role via this endpoint (any email/roleId fields in body are ignored)
  - Return updated profile data
  - Audit log: "user.profile_updated"

  **Part B: Session management API**

  Create `app/api/org/[slug]/sessions/route.ts`:

  GET handler:
  - `requireOrgAuth()`
  - Call `listUserSessions(user.id, organization.id)`
  - Enrich each session with parsed user agent (browser, os, device) from lib/user-agent.ts
  - Mark the current session by comparing session tokens (extract current token from Authorization header)
  - Return: `{ sessions: [{ id, browser, os, device, ipAddress, lastUsedAt, createdAt, isCurrent }] }`

  Create `app/api/org/[slug]/sessions/[sessionId]/route.ts`:

  DELETE handler:
  - `requireOrgAuth()`
  - Extract sessionId from URL params
  - Extract current session token from Authorization header
  - Find the current session to get its ID
  - Call `revokeSession(sessionId, currentSessionId)` -- validates cannot revoke current session
  - Return `{ success: true }`

  **Part C: Force-logout API (for Org Admin)**

  Create `app/api/org/[slug]/admin/users/[userId]/force-logout/route.ts`:

  POST handler:
  - `requireOrgAdmin()`
  - Extract userId from URL params
  - Validate userId belongs to this org (find OrgMember)
  - Extract current admin's session ID to preserve if admin is force-logging out themselves (edge case)
  - Call `forceLogoutUser(userId, organization.id, currentSessionId)`
  - Return `{ success: true, sessionsRevoked: count }`
  - Audit log: "user.force_logout"
