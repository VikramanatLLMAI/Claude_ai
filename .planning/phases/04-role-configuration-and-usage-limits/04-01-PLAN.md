<task type="auto">
  <name>Task 2: Service layer modules</name>
  <files>lib/services/usage-service.ts, lib/services/role-service.ts, lib/services/session-service.ts, lib/services/password-policy-service.ts, lib/user-agent.ts</files>
  <action>
  Create 4 service modules and 1 utility following the existing service pattern (see lib/services/audit-service.ts, lib/services/model-registry-service.ts).

  **lib/services/usage-service.ts:**
  - `checkUserUsageLimits(tenantDb, userId, role)` -- Rolling 24-hour window check. Uses `tenantDb.usageRecord.aggregate()` with `where: { userId, createdAt: { gte: new Date(Date.now() - 24 * 60 * 60 * 1000) } }`. Returns `{ allowed: boolean, warning: boolean, blocked: boolean, requestStatus: { current, limit, percentage } | null, tokenStatus: { current, limit, percentage } | null, resetAt: string | null }`. If role.dailyRequestLimit and role.dailyTokenLimit are both null, return `{ allowed: true }` immediately (unlimited). Use single aggregate query with both `_count.id` and `_sum` for inputTokens + outputTokens + thinkingTokens. Calculate resetAt from earliest usage record in the window.
  - `getUserUsageSummary(tenantDb, userId, role)` -- Same rolling window query but returns enriched data for usage status API (used by chat UI polling).
  - `getOrgUsageSummary(tenantDb, orgId, timeRange?)` -- Aggregate usage for the entire org. Returns per-user breakdown, per-model breakdown, total requests/tokens. Used by admin usage dashboard.
  - `getOrgMonthlyUsage(tenantDb, orgId)` -- Aggregate for current calendar month. Used for monthly ceiling check.
  - `checkOrgMonthlyCeiling(org, orgSettings, monthlyUsage)` -- Validates org usage against ceiling. Returns `{ allowed: boolean, requestStatus, tokenStatus }`.

  **lib/services/role-service.ts:**
  - `createRole(tenantDb, orgId, data, auditContext)` -- Create a custom role within a transaction. Validates: name uniqueness within org (catch Prisma unique constraint error), reasonable limits. Logs to audit. Returns created role.
  - `updateRole(tenantDb, roleId, data, auditContext)` -- Update any role (system or custom). System roles can be renamed, have description changed, models changed, limits changed, etc. Only thing system roles can't do: be deleted. Logs to audit. Returns updated role.
  - `deleteRole(tenantDb, roleId, auditContext)` -- Delete custom role. Validates: `isSystemRole === false`, no assigned members (check `_count.members`). If role is org's defaultRoleId, set defaultRoleId to null (ODEF-02). Logs to audit.
  - `getRoleWithMembers(tenantDb, roleId)` -- Get role with member count and member list.

  **lib/services/session-service.ts:**
  - `listUserSessions(userId, orgId?)` -- Uses raw prisma (not tenantDb, sessions are not org-scoped). Returns sessions for user, optionally filtered by orgId. Each session includes: id, userAgent (raw), ipAddress, createdAt, lastUsedAt, isCurrent (compared by token from request).
  - `revokeSession(sessionId, currentSessionId)` -- Delete a specific session. Validates: cannot revoke current session (would log self out). Returns success.
  - `forceLogoutUser(userId, orgId?, currentSessionId?)` -- Delete ALL sessions for a user, optionally filtered by orgId. If currentSessionId provided, preserve it (so the admin doing the force-logout doesn't log themselves out if forcing their own logout).

  **lib/services/password-policy-service.ts:**
  - `getPasswordPolicy(orgId)` -- Get password policy for org (raw prisma, PasswordPolicy is org-level). Returns policy or null (no policy = defaults).
  - `updatePasswordPolicy(orgId, data, auditContext)` -- Upsert password policy. Logs to audit. Returns updated policy.
  - `validatePasswordAgainstPolicy(password, policy)` -- Validate a password string against policy rules. Returns `{ valid: boolean, errors: string[] }`. Checks: minLength, requireUppercase, requireLowercase, requireNumbers, requireSpecialChars.
  - `checkPasswordChangeRequired(user, orgMember, policy)` -- Check if user must change password. Returns `{ required: boolean, reason: 'admin_forced' | 'expired' | null }`. Checks: (1) orgMember.forcePasswordChange flag, (2) password expiry (user.passwordChangedAt + policy.expiryDays < now).
  - `forcePasswordReset(tenantDb, userIds, orgId, auditContext)` -- Set forcePasswordChange=true on specified OrgMembers. Logs to audit per user.

  **lib/user-agent.ts:**
  - `parseUserAgent(ua: string | null)` -- Lightweight regex-based parser. Returns `{ browser: string, os: string, device: string }`. No external library. Browser: Chrome, Firefox, Safari, Edge, Opera, Unknown. OS: Windows, macOS, Linux, Android, iOS, Unknown. Device: Desktop, Mobile, Tablet.

  All services use raw prisma for non-tenant-scoped models (Session, User, PasswordPolicy) and tenantDb for tenant-scoped models (UsageRecord, Role, OrgMember, OrgSettings). Follow the established pattern from audit-service.ts: export named functions, use transactions for mutations with audit logging.

  ```typescript
  "use client"

  import * as React from "react"
  import * as TabsPrimitive from "@radix-ui/react-tabs"
  import { cn } from "@/lib/utils"

  const Tabs = TabsPrimitive.Root

  const TabsList = React.forwardRef<
    React.ComponentRef<typeof TabsPrimitive.List>,
    React.ComponentPropsWithoutRef<typeof TabsPrimitive.List>
  >(({ className, ...props }, ref) => (
    <TabsPrimitive.List
      ref={ref}
      className={cn(
        "inline-flex h-9 items-center justify-center rounded-lg bg-muted p-1 text-muted-foreground",
        className
      )}
      {...props}
    />
  ))
  TabsList.displayName = TabsPrimitive.List.displayName

  const TabsTrigger = React.forwardRef<
    React.ComponentRef<typeof TabsPrimitive.Trigger>,
    React.ComponentPropsWithoutRef<typeof TabsPrimitive.Trigger>
  >(({ className, ...props }, ref) => (
    <TabsPrimitive.Trigger
      ref={ref}
      className={cn(
        "inline-flex items-center justify-center whitespace-nowrap rounded-md px-3 py-1 text-sm font-medium ring-offset-background transition-all focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50 data-[state=active]:bg-background data-[state=active]:text-foreground data-[state=active]:shadow",
        className
      )}
      {...props}
    />
  ))
  TabsTrigger.displayName = TabsPrimitive.Trigger.displayName

  const TabsContent = React.forwardRef<
    React.ComponentRef<typeof TabsPrimitive.Content>,
    React.ComponentPropsWithoutRef<typeof TabsPrimitive.Content>
  >(({ className, ...props }, ref) => (
    <TabsPrimitive.Content
      ref={ref}
      className={cn(
        "mt-2 ring-offset-background focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2",
        className
      )}
      {...props}
    />
  ))
  TabsContent.displayName = TabsPrimitive.Content.displayName

  export { Tabs, TabsList, TabsTrigger, TabsContent }
  ```
