**1. Validation schema (add to lib/validation.ts):**

```typescript
const AuditLogFilterSchema = z.object({
  page: z.coerce.number().int().min(1).default(1),
  pageSize: z.coerce.number().int().min(10).max(50).default(25),
  startDate: z.string().datetime().optional(),
  endDate: z.string().datetime().optional(),
  organizationId: z.string().uuid().optional(),
  action: z.string().optional(),
  userId: z.string().uuid().optional(),
  sortBy: z.enum(["createdAt", "action"]).default("createdAt"),
  sortOrder: z.enum(["asc", "desc"]).default("desc"),
})
```

**2. Service (lib/services/audit-log-service.ts):**

Uses raw `prisma` (cross-org, platform-level).

`listAuditLogs(filters)`:
- Build Prisma `where` clause from filters:
  - `createdAt: { gte: startDate, lte: endDate }` if provided
  - `organizationId` if provided
  - `action: { contains: filters.action }` if provided (partial match for filter)
  - `userId` if provided
- Include `organization` (select name, slug), `user` (select name, email)
- Apply pagination: `skip: (page - 1) * pageSize`, `take: pageSize`
- Apply sorting: `orderBy: { [sortBy]: sortOrder }`
- Also query total count with same where clause (for pagination metadata)
- Return `{ logs: AuditLog[], total: number, page: number, pageSize: number, totalPages: number }`

`exportAuditLogs(filters, format)`:
- Same where clause as listAuditLogs, but no pagination (fetch all matching)
- Set a reasonable limit (e.g., 10000 rows max)
- If format === "csv": Generate CSV string with proper escaping, UTF-8 BOM for Excel compatibility
  - Headers: Date, User, Email, Action, Target Type, Target ID, Organization, IP Address, Details
  - Escape commas and quotes in values
- If format === "json": Return array of objects
- Return `{ data: string, contentType: string, filename: string }`

`getAvailableActions()`:
- SELECT DISTINCT action FROM audit_logs ORDER BY action
- Used for filter dropdown in UI

`getAuditLogUsers()`:
- SELECT DISTINCT user_id, user.name, user.email FROM audit_logs JOIN users
- Used for user filter dropdown in UI

**3. API routes:**

`GET /api/super-admin/audit-logs/` (route.ts):
- requireSuperAdmin

- Call listAuditLogs(filters)
- Return JSON with `{ logs, total, page, pageSize, totalPages }`

`GET /api/super-admin/audit-logs/export` (export/route.ts):

  - JSON: `application/json`, Content-Disposition: `attachment; filename="audit-logs-{date}.json"`

Create the Audit Logs page at `app/super-admin/audit-logs/page.tsx`.

**Important:** This page uses SERVER-SIDE pagination (unlike other tables that use client-side). This means the DataTable component's built-in pagination won't work as-is. Instead:

- Use `useReactTable` directly in the page with `manualPagination: true` and `pageCount` from server response
- The table displays the current page of data (not all data)
- Pagination controls call the API with page/pageSize params

Or simpler approach: Use DataTable for rendering but manage pagination state externally, passing just the current page's data to DataTable with `pageSize` matching the data length (so DataTable shows one "page" of server-returned data). Build custom pagination controls that call the API.

**Recommended approach:** Build the audit log table inline (using useReactTable directly) rather than through the generic DataTable component. This gives full control over server-side pagination.
