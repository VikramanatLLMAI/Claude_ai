<task type="auto">
  <name>Task 1: Install TanStack Table + Schema changes</name>
  <files>package.json, prisma/schema.prisma</files>
  <action>
1. Install TanStack Table:
   ```
   npm install @tanstack/react-table --legacy-peer-deps
   ```

2. Add PlatformSettings model to prisma/schema.prisma:
   ```prisma
   model PlatformSettings {
     id                String   @id @default("singleton")
     platformName      String   @default("LLMatscale.ai") @map("platform_name")
     sessionExpiryDays Int      @default(30) @map("session_expiry_days")
     maintenanceMode   Boolean  @default(false) @map("maintenance_mode")
     featureToggles    Json     @default("{}") @map("feature_toggles")
     createdAt         DateTime @default(now()) @map("created_at")
     updatedAt         DateTime @updatedAt @map("updated_at")

     @@map("platform_settings")
   }
   ```

3. Add PlatformApiKeyAssignment junction table:
   ```prisma
   model PlatformApiKeyAssignment {
     id             String   @id @default(uuid())
     apiKeyId       String   @map("api_key_id")
     organizationId String   @map("organization_id")
     assignedAt     DateTime @default(now()) @map("assigned_at")

     apiKey       PlatformApiKey @relation(fields: [apiKeyId], references: [id], onDelete: Cascade)
     organization Organization   @relation(fields: [organizationId], references: [id], onDelete: Cascade)

     @@unique([apiKeyId, organizationId])
     @@map("platform_api_key_assignments")
   }
   ```

4. Update PlatformApiKey model: Keep the existing `organizationId` field for backward compat but add a `assignments PlatformApiKeyAssignment[]` relation.

5. Add `apiKeyAssignments PlatformApiKeyAssignment[]` back-relation on Organization model.

6. Run `npx prisma db push` to apply schema changes.

7. Run `npx prisma generate` to regenerate the client.
  </action>
