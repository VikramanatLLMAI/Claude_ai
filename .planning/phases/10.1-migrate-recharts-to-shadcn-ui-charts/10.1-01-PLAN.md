<task type="auto">
  <name>Task 1: Create chart.tsx wrapper and chart-utils.tsx shared utilities</name>
  <files>components/ui/chart.tsx, components/admin/chart-utils.tsx</files>
  <action>
    **1. Create `components/ui/chart.tsx`** -- the shadcn/ui chart wrapper component.

    This is a manual creation (no shadcn CLI -- project lacks components.json). Follow the official shadcn/ui chart.tsx pattern, exporting:
    - `ChartConfig` type: `Record<string, { label?: React.ReactNode; icon?: React.ComponentType; color?: string; theme?: Record<"light" | "dark", string> }>`
    - `ChartContainer`: Wraps Recharts charts, replaces ResponsiveContainer, injects `--color-{key}` CSS variables from ChartConfig onto a container div. Must accept `config: ChartConfig`, `className`, `children`, and spread remaining props onto the outer div.
    - `ChartTooltip`: Re-export of Recharts `Tooltip` (used as `<ChartTooltip content={<ChartTooltipContent />} />`)
    - `ChartTooltipContent`: Themed tooltip content component with indicator dots, label from ChartConfig, formatted values. Props include `indicator?: "line" | "dot" | "dashed"`, `hideLabel?: boolean`, `hideIndicator?: boolean`, `nameKey?: string`, `labelKey?: string`, `labelFormatter?`, `formatter?`. Must use `useChart()` context to read ChartConfig for label resolution.
    - `ChartLegend`: Re-export of Recharts `Legend`
    - `ChartLegendContent`: Themed legend content with color indicators. Props include `nameKey?: string`, `hideIcon?: boolean`.
    - `ChartStyle`: Optional component that generates `<style>` tag with CSS variables (for SSR).

    **Recharts v3 compatibility:** The project uses recharts 3.7.0. The official shadcn chart.tsx targets v2. If TypeScript errors arise on tooltip/legend payload types, use `as any` casts (established project pattern per CLAUDE.md). Key difference: Recharts v3 removes internal types like `Payload` from tooltip components -- type the payload as `any` in ChartTooltipContent/ChartLegendContent.

    Use a React context (`ChartContext`) to provide the ChartConfig to child components (ChartTooltipContent, ChartLegendContent).

    **2. Create `components/admin/chart-utils.tsx`** -- shared utilities extracted from the duplicate code in both chart files.

    Extract from the existing `analytics-charts.tsx` and `org-analytics-charts.tsx`:
    - `EmptyState` component: Accepts `{ message: string; icon?: "chart" | "check" }`, renders centered muted message with optional icon. Use the existing implementation from analytics-charts.tsx.
    - `ExportButton` component: Accepts `{ onClick: () => void }`, renders a ghost Button with Download icon. Extract from org-analytics-charts.tsx (SA charts don't have export).
    - `formatTokens(value: number): string` -- formats token counts (e.g., 1234567 -> "1.2M")
    - `formatDate(date: string): string` -- formats date strings for axis labels (e.g., "Jan 15")
    - `formatMs(ms: number): string` -- formats milliseconds for response time display
    - `ERROR_COLORS: Record<string, string>` -- semantic hex colors for error types: `{ rate_limit: "#ef4444", context_length: "#f59e0b", api_error: "#8b5cf6", timeout: "#06b6d4", other: "#94a3b8" }`
    - `INVITATION_COLORS: Record<string, string>` -- semantic hex colors for invitation statuses: `{ PENDING: "#f59e0b", ACCEPTED: "#10b981", EXPIRED: "#94a3b8", REVOKED: "#ef4444" }`

    Both files must have `"use client"` directive.
  </action>
