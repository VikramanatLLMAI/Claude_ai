<task id="1" title="Add UI fallback for null lastUsedAt in settings modal">
In `components/settings-modal.tsx`, find the session list rendering where `lastUsedAt` is displayed (around the "Active" timestamp area). Update the logic so that:
- If `lastUsedAt` is non-null, display it as-is (relative time like "Active 2 hours ago")

This ensures no session ever shows "Active Never" regardless of data state.
</task>

- Run: `UPDATE "Session" SET "lastUsedAt" = "createdAt" WHERE "lastUsedAt" IS NULL`
- Log the number of rows updated
- Exit cleanly

Add a run command note in the script header comment explaining usage:
`npx tsx scripts/backfill-session-timestamps.ts`
</task>
