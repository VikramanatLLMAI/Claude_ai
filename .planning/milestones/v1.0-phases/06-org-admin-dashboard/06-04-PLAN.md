  <action>
Create `app/org/[slug]/admin/invitations/page.tsx` following established DataTable page patterns.

**Page structure:**

1. **Page header:** SidebarTrigger + Mail icon + "Invitations" title + "Send Invitation" primary button (right side)

2. **Filter tabs (per CONTEXT.md):**
   - Use Radix Tabs or custom tab buttons: All, Pending, Accepted, Expired
   - Each tab shows count badge (e.g., "Pending (3)")
   - Tabs filter the displayed data client-side (invitation list is typically small enough)
   - "All" tab shows unfiltered data

3. **DataTable columns:**
   - Email: text with font-medium
   - Role: Badge variant="outline" showing role name
   - Status: Badge with color coding per CONTEXT.md — pending=amber, accepted=green, expired=gray, revoked=red
   - Sent Date: formatted date (e.g., "Mar 5, 2026")
   - Expires Date: formatted date, show "Expired" text if past
   - Actions: Three-dot DropdownMenu (MoreVertical trigger)
     - For PENDING status: "Resend" and "Revoke" items
     - For ACCEPTED/EXPIRED/REVOKED: no actions (empty or no menu shown)

4. **Send Invitation modal (Dialog):**
   - Triggered by "Send Invitation" button
   - Fields:
     - Email input (required, email validation)
     - Role dropdown (Select component, populated from /api/org/{slug}/admin/roles)
     - Welcome message textarea (optional, max 500 chars)
   - Submit: POST /api/org/{slug}/invitations with { email, roleId, message }
   - Success: toast.success("Invitation sent to {email}"), close modal, refresh list
   - Error: toast.error with API error message (e.g., "User already invited")

5. **Row actions:**
   - Resend: POST /api/org/{slug}/invitations/{id}/resend → toast.success("Invitation resent")
   - Revoke: ConfirmationDialog first ("Revoke invitation to {email}?") → POST /api/org/{slug}/invitations/{id}/revoke → toast.success("Invitation revoked")

**State management:**
- invitations: Invitation[]
- loading: boolean
- activeTab: 'all' | 'pending' | 'accepted' | 'expired'
- roles: { id, name }[] for dropdown
- sendDialogOpen: boolean
- form state for send dialog: { email, roleId, message }

**Data fetching:**
- useEffect on mount: fetch invitations from /api/org/{slug}/invitations
- Also fetch roles from /api/org/{slug}/admin/roles for the role dropdown

**Tab filtering:**
- Compute filteredInvitations from invitations based on activeTab
- Compute counts: pendingCount, acceptedCount, expiredCount for tab badges

**Empty states:**
- No invitations at all: "No invitations yet. Send your first invitation to add team members."
- No invitations matching filter: "No {status} invitations found."
