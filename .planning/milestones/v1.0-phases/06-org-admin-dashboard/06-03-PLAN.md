  <action>
Create `app/org/[slug]/admin/users/page.tsx` following the established DataTable page pattern (reference super-admin/organizations/page.tsx).

**Page structure:**
1. Page header: SidebarTrigger + Users icon + "Members" title
2. Filter bar below header:
   - Text input for search (name/email), debounced 300ms
   - Role dropdown (populated from ?roles=true param on users API)
   - Status dropdown: All, Active, Suspended, Inactive
   - Clear filters button (shown when any filter active)
3. DataTable with columns (per CONTEXT.md compact table decision):
   - Checkbox column (for bulk selection, e.stopPropagation on clicks)
   - User column: Avatar (8x8, initials fallback) + Name (font-medium) + Email (text-xs muted) in single cell
   - Role column: Badge variant="outline" with role name
   - Status column: Badge with color coding — Active=green, Suspended=red, Inactive=gray, Pending=amber
   - Last Active column: relative time format (e.g., "2 days ago", "Never")
4. Row click handler: opens side panel (but NOT checkbox clicks — use e.stopPropagation per RESEARCH.md pitfall)
5. Floating bulk action bar (fixed bottom-6, centered):
   - Shown when rowSelection has entries
   - Shows "N selected" count
   - Buttons: Suspend, Change Role (DropdownMenu), Force Logout
   - Each bulk action uses Promise.allSettled for parallel execution
   - Reports partial success/failures via toast

**State management:**
- users: UserRow[]
- loading: boolean
- filters: { search, role, status }
- rowSelection: Record<string, boolean> (TanStack row selection)
- selectedUser: UserRow | null (for side panel)
- roles: { id, name }[] (for filter dropdown and role change)

**Data fetching:**
- useEffect on filters change → fetch /api/org/{slug}/admin/users with params
- Also fetch ?roles=true on mount for role dropdown options
- Extract orgSlug from URL path using existing getOrgSlugFromUrl helper or params

**Bulk actions:**
- Bulk suspend: POST PATCH for each selected user with action='suspend', Promise.allSettled
- Bulk change role: Show DropdownMenu with roles, select one, PATCH each with action='changeRole'
- Bulk force logout: POST to /api/org/{slug}/admin/users/{userId}/force-logout for each
- After bulk action: clear selection, refetch users, show toast with results
- ConfirmationDialog before destructive bulk actions (suspend)

Integrate UserDetailPanel (from Task 2) — render at page level:
```tsx
<UserDetailPanel
  user={selectedUser}
  open={!!selectedUser}
  onClose={() => setSelectedUser(null)}
  roles={roles}
  onUserUpdated={fetchUsers}
  orgSlug={orgSlug}
/>
```
