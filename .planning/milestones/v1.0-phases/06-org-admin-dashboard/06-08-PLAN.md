Current broken code:
```typescript
function getCurrentUserId(): string | null {
  if (typeof window === "undefined") return null
  try {
    const raw = localStorage.getItem("llmatscale_user")
    if (!raw) return null
    const user = JSON.parse(raw)
    return user.id || null
  } catch {
    return null
  }
}
```

Replace with:
```typescript
function getCurrentUserId(): string | null {
  if (typeof window === "undefined") return null
  try {
    const raw = localStorage.getItem("llmatscale_auth_session")
    if (!raw) return null
    const session = JSON.parse(raw)
    return session.user?.id || null
  } catch {
    return null
  }
}
```

Key changes:
1. Read from `"llmatscale_auth_session"` (the key used by org-login-page, register-page, and all other auth code throughout the app)
2. Parse the session object and access `session.user.id` (the session stores `{ user: { id, ... }, signedInAt, ... }`)
3. Use optional chaining `session.user?.id` for safety

No other changes needed. The `isSelf` check in `user-detail-panel.tsx` (line 98) and all `disabled={isSelf || actionLoading}` guards on buttons (lines 246, 274, 285, 298, 310, 321) already work correctly -- they just need `getCurrentUserId()` to return the actual user ID.
