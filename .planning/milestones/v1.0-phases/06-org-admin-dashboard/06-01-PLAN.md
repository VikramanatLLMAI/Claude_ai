  <action>
Create `lib/services/org-user-service.ts` with the following functions. Use raw `prisma` (not tenantDb) since OrgMember joins User which is not org-scoped. All mutations wrap in `prisma.$transaction()` with `auditLog.record()` co-located.

**listOrgMembers(orgId, filters: { search?, role?, status? }):**
- Query OrgMember where organizationId=orgId, include user (id, name, email, avatarBase64), role (id, name, permissions)
- Status filter: if "inactive" → where status='ACTIVE' AND lastActiveAt < 30 days ago. If "suspended" → where status='SUSPENDED'. If "active" → where status='ACTIVE' AND lastActiveAt >= 30 days ago (or null lastActiveAt treated as active).
- If search provided, filter by user.name or user.email (case-insensitive, do in Prisma where clause using contains/mode:insensitive)
- If role provided, filter by roleId
- Include user's customInstructions from orgMember for the side panel (OUSR-10)
- Return array of members ordered by joinedAt desc

**suspendOrgMember(orgId, userId, actorId, ipAddress):**
- SAFE-01: Cannot suspend self (userId !== actorId)
- SAFE-02: If target has org_admin permission, check adminCount > 1
- Update orgMember.status to 'SUSPENDED'
- Delete all sessions for this user in this org
- Record audit log action 'user.suspended'

**activateOrgMember(orgId, userId, actorId, ipAddress):**
- Update orgMember.status to 'ACTIVE'
- Record audit log action 'user.activated'

**deleteOrgMember(orgId, userId, actorId, ipAddress):**
- SAFE-01: Cannot delete self
- SAFE-02: If target has org_admin permission, check adminCount > 1
- Delete all sessions, then delete orgMember record
- Record audit log action 'user.deleted'
- Note: Do NOT delete the User record — only the org membership

**changeOrgMemberRole(orgId, userId, newRoleId, actorId, ipAddress):**
- SAFE-02: If removing org_admin permission (old role has it, new role doesn't), check adminCount > 1
- Update orgMember.roleId
- Record audit log action 'user.role_changed' with metadata: { fromRoleId, toRoleId }

**promoteToAdmin(orgId, userId, actorId, ipAddress):**
- Find the org's Technical role (or any role with org_admin permission)
- Update orgMember.roleId to that role
- Record audit log action 'user.promoted_to_admin'

**updateOrgMemberName(orgId, userId, newName, actorId, ipAddress):**
- Update user.name (on User model, not OrgMember)
- Record audit log action 'user.name_updated'

Create `app/api/org/[slug]/admin/users/route.ts`:
- GET: requireOrgAdmin → extract search/role/status from searchParams → call listOrgMembers → return JSON with { users: [...] }
- Also support ?roles=true param to return available roles for dropdowns (query all roles for this org)

Create `app/api/org/[slug]/admin/users/[userId]/route.ts`:
- PATCH: requireOrgAdmin → Zod validate body → dispatch to appropriate service function based on body.action field:
  - action='suspend' → suspendOrgMember
  - action='activate' → activateOrgMember
  - action='changeRole' → changeOrgMemberRole (body.roleId required)
  - action='promote' → promoteToAdmin
  - action='updateName' → updateOrgMemberName (body.name required)
- DELETE: requireOrgAdmin → deleteOrgMember
- Return appropriate error messages for safety violations (400 status)
