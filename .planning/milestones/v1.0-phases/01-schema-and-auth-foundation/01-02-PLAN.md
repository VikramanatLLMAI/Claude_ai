Build the enriched auth middleware (requireOrgAuth, requireSuperAdmin), org context resolution, and migrate all existing API routes to use tenant-scoped data access.

**New type: OrgAuthContext (AUTH-01)**
```typescript
export interface OrgAuthContext {
  user: User;
  orgMember: OrgMember & { organization: Organization; role: Role };
  organization: Organization;
  role: Role;
  permissions: string[];
  tenantDb: TenantPrismaClient; // Pre-built scoped client for convenience
}
```

**New type: SuperAdminContext (AUTH-06)**
```typescript
export interface SuperAdminContext {
  user: User & { isSuperAdmin: true };
}
```

**New function: requireOrgAuth(req) (AUTH-02)**
1. Call existing `validateSession(req)` to get user
2. If not authenticated, return 401 NextResponse
3. If user.isSuperAdmin, return 403 with "Super Admin cannot access org-scoped resources" (AUTH-06)
4. Call `resolveOrgSlug(req)` to get org slug
5. If no slug, return 400 with "Organization context required"
6. Query prisma.orgMember.findFirst with:
   - where: userId, organization slug matches, org deletedAt is null, org status is "ACTIVE"
   - include: { organization: true, role: true }
7. If no membership found, return 403 "Forbidden"
8. If orgMember.status is not "ACTIVE", return 403 "Account suspended"
9. Build and return OrgAuthContext with tenantPrisma(organization.id) pre-created
10. Update orgMember.lastActiveAt to now() (fire-and-forget, don't await)

All authorization enforced at route handler level per AUTH-07 (not proxy/middleware).

**New function: requireSuperAdmin(req) (AUTH-03)**
1. Call existing `validateSession(req)` to get user
2. If not authenticated, return 401 NextResponse
3. If !user.isSuperAdmin, return 403 "Forbidden"
4. Return SuperAdminContext

**New function: requireOrgAdmin(req)** (convenience wrapper for ROUTE-03)
1. Call requireOrgAuth(req)
2. If error response, return it
3. Check if role permissions include "org_admin" OR role name is "Org Admin" (flexible matching)
4. If not admin, return 403 "Org Admin access required"
5. Return OrgAuthContext

**Systematic API route migration to multi-tenant pattern (ROUTE-05, AUTH-07)**

Every org-scoped API route must be updated from:
```typescript
const auth = await requireAuth(req);
if (auth instanceof NextResponse) return auth;
const { user } = auth;
```
To:
```typescript
const auth = await requireOrgAuth(req);
if (auth instanceof NextResponse) return auth;
const { user, organization, role, tenantDb } = auth;
```

Then replace all `prisma.conversation.findMany(...)` calls with `tenantDb.conversation.findMany(...)` (the tenant client auto-injects organizationId).
