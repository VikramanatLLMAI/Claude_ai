<objective>
Close the final UAT gap from 04-UAT-final2.md: org users navigating to /admin/* paths receive a 404 "Organization not found" error instead of being redirected to /org/{slug}/chat.

Purpose: The admin layout guard (app/admin/layout.tsx) already has correct redirect logic for org users — but it only loads when a matching page exists. Unknown /admin/* paths (e.g., /admin/dashboard) have no page, so Next.js skips the layout entirely and renders the root not-found.tsx. Adding a catch-all page fixes this by ensuring the admin layout always loads for any /admin/* URL.

Output: One new file — app/admin/[...catchAll]/page.tsx — a client component that redirects Super Admins to /admin/models. The admin layout's existing useEffect handles org user redirects automatically once the layout is loaded.
</objective>

    - For valid Super Admin sessions: the layout renders normally, then this catch-all redirects to /admin/models

    Use this exact implementation (mirrors app/admin/page.tsx):

    ```tsx
    "use client"

    import { useEffect } from "react"
    import { useRouter } from "next/navigation"

    /**
     * Catch-all page for unknown /admin/* paths.
     *
     * Purpose: Ensures the admin layout loads for any /admin/* URL that does
     * not have a dedicated page (e.g., /admin/dashboard). Without this page,
     * Next.js skips the admin layout and renders the root not-found.tsx instead,
     * breaking the org-user redirect guard in admin layout's useEffect.
     *
     * - Super Admin: redirected to /admin/models (same as root /admin page)
     * - Org users: handled by admin layout's useEffect (redirects to /org/{slug}/chat)
     * - Unauthenticated: handled by admin layout's useEffect (redirects to /admin/login)
     */
    export default function AdminCatchAllPage() {
      const router = useRouter()

      useEffect(() => {
        router.replace("/admin/models")
      }, [router])

      return null
    }
    ```

    Do NOT add any auth logic to this page — the admin layout owns all auth/redirect decisions.
    Do NOT use useSearchParams, useParams, or access the catchAll param — it is not needed.
