**API Routes:**

1. `GET /api/org/[slug]/admin/conversations` — List conversations with query params: userId, dateFrom, dateTo, model, page, pageSize. requireOrgAdmin. Also check OrgSettings.conversationVisibility is true, return 403 if not enabled.

2. `GET /api/org/[slug]/admin/conversations/[id]` — Get conversation detail. requireOrgAdmin + visibility check.

3. `POST /api/org/[slug]/admin/conversations/export` — Body: `{ conversationIds: string[] }`. Return JSON array of conversations. If single conversation, return JSON directly. If multiple, use JSZip to create a zip file (install jszip if not present: `npm install jszip`). requireOrgAdmin + visibility check.

4. `GET/PATCH /api/org/[slug]/admin/settings/visibility` — GET returns current `conversationVisibility` boolean. PATCH toggles it. requireOrgAdmin. OVIS-07: Log toggle change in audit logs.

5. `GET/PUT /api/org/[slug]/admin/onboarding` — Org Admin manages onboarding text. GET returns current config. PUT updates text + bumps version.

6. `GET/POST /api/org/[slug]/onboarding` — User-facing. GET: check if onboarding required + return onboarding text. POST: record acceptance. Uses requireOrgAuth (any org member).
