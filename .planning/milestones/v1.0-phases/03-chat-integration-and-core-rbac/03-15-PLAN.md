In `app/org/[slug]/admin/instructions/page.tsx`, the `beforeunload` handler (lines 104-112) correctly warns on browser close/reload. However, Next.js App Router client-side navigation (clicking sidebar links) bypasses this entirely. Fix:

1. **Keep the existing `beforeunload` handler** -- it works for browser close/refresh.

2. **Add a navigation interception effect** below the existing beforeunload effect:
   - Use `window.addEventListener('click', handler, true)` (capture phase) to intercept clicks on anchor tags and buttons that would trigger navigation.
   - In the handler:
     - If `anyDirty` is false, do nothing (let navigation proceed).
     - If the click target (or its closest ancestor) is an `<a>` element with an `href` that differs from the current page:
       - Call `e.preventDefault()` and `e.stopPropagation()` to block the navigation.
       - Show `window.confirm("You have unsaved changes. Are you sure you want to leave?")`.
       - If the user confirms, programmatically navigate using `window.location.href = href` (which will trigger a full page load and work reliably).
       - If the user cancels, do nothing (stay on page).
   - Use a ref for the `anyDirty` value so the handler closure always sees the latest value without re-registering:
     ```typescript
     const anyDirtyRef = React.useRef(anyDirty)
     React.useEffect(() => { anyDirtyRef.current = anyDirty }, [anyDirty])
     ```

3. **Implementation pattern:**
```typescript
// Ref to track dirty state in event handler without re-registering
const anyDirtyRef = React.useRef(anyDirty)
React.useEffect(() => { anyDirtyRef.current = anyDirty }, [anyDirty])

// Intercept client-side navigation when dirty
React.useEffect(() => {
  const handleClick = (e: MouseEvent) => {
    if (!anyDirtyRef.current) return

    const target = (e.target as HTMLElement).closest('a[href]')
    if (!target) return

    const href = (target as HTMLAnchorElement).getAttribute('href')
    if (!href) return

    // Only intercept internal navigation away from this page
    const currentPath = window.location.pathname
    if (href === currentPath || href === '#') return

    e.preventDefault()
    e.stopPropagation()

    const confirmed = window.confirm(
      'You have unsaved changes. Are you sure you want to leave this page?'
    )
    if (confirmed) {
      window.location.href = href
    }
  }

  document.addEventListener('click', handleClick, true)
  return () => document.removeEventListener('click', handleClick, true)
}, [])
```

4. **Also intercept browser back/forward navigation** (popstate):
```typescript
React.useEffect(() => {
  const handlePopState = () => {
    if (!anyDirtyRef.current) return

    const confirmed = window.confirm(
      'You have unsaved changes. Are you sure you want to leave this page?'
    )
    if (!confirmed) {
      // Push the current URL back to undo the navigation
      window.history.pushState(null, '', window.location.href)
    }
  }

  window.addEventListener('popstate', handlePopState)
  return () => window.removeEventListener('popstate', handlePopState)
}, [])
```

Important: The click handler uses capture phase (`true` as third arg) so it fires before Next.js Link component's handler. The `anyDirtyRef` pattern avoids re-registering the event listener on every dirty state change.
