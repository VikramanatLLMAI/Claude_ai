1. **Last saved timestamps on instruction editors:**
   - In `app/org/[slug]/admin/instructions/page.tsx`:
     - Track `orgLastSaved: Date | null` and `roleLastSaved: Record<string, Date | null>` state
     - On successful save, set the timestamp to `new Date()`
     - Display below each Save button: "Last saved: {relative time}" (e.g., "Last saved: just now", "Last saved: 2 minutes ago")
     - Use a simple relative time formatter:
       ```typescript
       function formatRelativeTime(date: Date): string {
         const seconds = Math.floor((Date.now() - date.getTime()) / 1000)
         if (seconds < 10) return "just now"
         if (seconds < 60) return `${seconds} seconds ago`
         const minutes = Math.floor(seconds / 60)
         if (minutes < 60) return `${minutes} minute${minutes > 1 ? 's' : ''} ago`
         const hours = Math.floor(minutes / 60)
         return `${hours} hour${hours > 1 ? 's' : ''} ago`
       }
       ```
     - Update the displayed time every 30 seconds with a `setInterval`
     - Style: `text-xs text-muted-foreground` below the save button
     - If never saved in this session, show nothing (don't show "Last saved: never")

2. **Enhanced empty states for instruction editors:**

   - Add a helpful description line above the textarea if not already present:
     - Org: "These instructions are included in every AI conversation for all users in your organization."
     - Role: "These instructions are included in addition to organization instructions for users with the {roleName} role."
