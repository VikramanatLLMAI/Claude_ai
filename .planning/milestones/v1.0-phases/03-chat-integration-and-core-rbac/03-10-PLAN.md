**Instructions page (`app/org/[slug]/admin/instructions/page.tsx`):**

1. **Toast notifications:**
   - Import `toast` from `@/components/ui/toast`
   - On org instructions save success: `toast.success("Organization instructions saved")`
   - On org instructions save error: `toast.error("Failed to save organization instructions")`
   - On role instructions save success: `toast.success("Instructions saved for {roleName} role")`
   - On role instructions save error: `toast.error("Failed to save instructions for {roleName} role")`
   - Remove the existing brief checkmark/fade animation — toast replaces it

2. **Unsaved changes tracking:**
   - Track dirty state per section: `orgDirty: boolean` and `roleDirty: Record<string, boolean>`
   - Compare current value vs last saved value to detect changes
   - Show a small colored dot (8px, `bg-amber-500 rounded-full`) next to the Save button when dirty
   - Add `beforeunload` event listener that warns when any section is dirty:
     ```typescript
     useEffect(() => {
       const handler = (e: BeforeUnloadEvent) => {
         if (anyDirty) { e.preventDefault() }
       }
       window.addEventListener('beforeunload', handler)
       return () => window.removeEventListener('beforeunload', handler)
     }, [anyDirty])
     ```

3. **Save button consistency:**
   - Make ALL save buttons use the same style: filled primary Button (not ghost/outline)
   - Use `variant="default"` (which is the filled primary style) for all save buttons
   - Disable the save button when there are no unsaved changes (not dirty)

**Roles page (`app/org/[slug]/admin/roles/page.tsx`):**

4. **Toast notifications for role settings save:**
   - Import `toast` from `@/components/ui/toast`
   - On settings save success: `toast.success("Settings saved for {roleName} role")`
   - On settings save error: `toast.error("Failed to save settings for {roleName} role")`

5. **Confirmation dialog for destructive role changes:**
   - Import `ConfirmationDialog` from `@/components/ui/confirmation-dialog`
   - When toggling Custom Instructions OFF or Personal MCP OFF:
     - Instead of saving immediately, show a confirmation dialog
     - Title: "Disable {featureName}?"
     - Description: "This will disable {featureName} for all users with the {roleName} role. Their existing settings will be preserved but inactive."
     - variant: "warning" (amber)
     - On confirm: proceed with the save
   - Toggling ON does NOT require confirmation (non-destructive)

6. **Max MCP server validation fix:**
   - When Personal MCP is enabled and max count is set to 0, enforce minimum of 1:
     - Set min attribute on the number input to 1 (when enabled)
     - On blur, if value < 1, auto-correct to 1
     - Show inline helper text: "Minimum 1 server when enabled"

7. **Toggle switch CSS transition animation:**
   - The Switch component from `@/components/ui/switch.tsx` likely uses Radix Switch
   - Add CSS transition to the thumb/indicator: `transition-transform duration-200 ease-in-out`
   - Add subtle background color transition: `transition-colors duration-200`
   - If the Switch component already has transitions, verify they work — otherwise add `data-[state=checked]:translate-x-5 transition-all duration-200`
