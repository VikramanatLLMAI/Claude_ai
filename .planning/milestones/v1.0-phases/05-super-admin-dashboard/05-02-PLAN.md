**1. DataTableColumnHeader (`components/admin/data-table-column-header.tsx`)**

"use client" component that renders a sortable column header with optional inline filter.

Props:
- `column`: Column instance from TanStack Table
- `title`: Display name string
- `enableFilter?: boolean` (default true)

Behavior:
- Click header text to toggle sort (asc -> desc -> none)
- Show ChevronUp / ChevronDown / ChevronsUpDown icon from lucide-react based on sort state
- Below the header text, render an Input component (from `@/components/ui/input`) for column filtering
- Filter input uses `column.setFilterValue()` on change
- Input has small styling: `h-7 text-xs` placeholder `Filter...`
- Header button uses `variant="ghost" size="sm"` from existing Button component
- When `enableFilter` is false, don't render the filter input

```typescript
import { Column } from "@tanstack/react-table"
import { ChevronUp, ChevronDown, ChevronsUpDown } from "lucide-react"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
```

**2. DataTablePagination (`components/admin/data-table-pagination.tsx`)**

"use client" component for table pagination controls.

Props:
- `table`: Table instance from TanStack Table

Layout (flex row, items-center, justify-between):
- Left: Row count text `"{filteredRows} row(s) total"` in `text-sm text-muted-foreground`
- Right: Rows-per-page selector (native `<select>` with options 10, 25, 50, styled `h-8 rounded-md border px-2 text-sm`) + page info text `"Page {current} of {total}"` + Previous/Next buttons using `Button variant="outline" size="sm"`
- Previous disabled when `!table.getCanPreviousPage()`
- Next disabled when `!table.getCanNextPage()`

**3. DataTable (`components/admin/data-table.tsx`)**

"use client" generic component `DataTable<TData, TValue>`.

Props:
- `columns: ColumnDef<TData, TValue>[]`
- `data: TData[]`
- `pageSize?: number` (default 10)
- `searchColumn?: string` — optional global search on a specific column
- `searchPlaceholder?: string` — placeholder for global search input

State:
- `sorting: SortingState` with `setSorting`
- `columnFilters: ColumnFiltersState` with `setColumnFilters`

Uses `useReactTable` with:
- `getCoreRowModel()`
- `getSortedRowModel()`
- `getFilteredRowModel()`
- `getPaginationRowModel()`
- `initialState: { pagination: { pageSize } }`

Rendering:
- Optional global search Input above the table (if `searchColumn` provided)
- `<div className="rounded-md border">` wrapper
- Standard HTML `<table className="w-full">` (not a Radix table -- TanStack Table is headless)
- `<thead>` with `table.getHeaderGroups()`, each `<tr>` has `border-b bg-muted/50`
- Each `<th>` uses `flexRender(header.column.columnDef.header, header.getContext())`
- `<tbody>` with `table.getRowModel().rows`, each `<tr>` has `border-b hover:bg-muted/30 transition-colors`
- Each `<td>` uses `flexRender(cell.column.columnDef.cell, cell.getContext())`
- Empty state: when no rows, show `<tr>` with single `<td colSpan={columns.length}>` centered "No results." text
- Below table: `<DataTablePagination table={table} />`

Styling must use existing Tailwind classes matching the admin panel aesthetic (muted backgrounds, subtle borders, consistent text sizes).

Export all three components as named exports.
