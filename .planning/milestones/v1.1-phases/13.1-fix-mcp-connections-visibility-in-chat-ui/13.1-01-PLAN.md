<objective>
Fix the backend MCP data flow so org-wide and role-scoped MCP tools are auto-included in chat, add source-prefixed tool names for frontend labeling, add new read-only API endpoints for MCP visibility, enforce personalMcpEnabled guardrails, and add the McpSource enum to the schema.

Purpose: The chat route currently only loads MCP tools that the frontend explicitly sends via activeMcpIds. Org/role MCPs are authorized but never loaded because the frontend does not know their IDs. This plan fixes the backend to auto-include org/role MCPs and provides the API surface for frontend visibility.

Output: Updated schema with McpSource enum, fixed chat route, two new read-only API endpoints, personalMcpEnabled guardrails on personal MCP CRUD, and enhanced /api/auth/me response.
</objective>
