## Tests

### 1. Settings Modal - Org MCP Read-Only Section
expected: Open Settings > MCP tab. Above the personal connections section, you should see a read-only section showing org-wide MCP connections with name, URL, tool count, and an "(Org)" badge. These are read-only (not editable).
result: pass

### 2. Settings Modal - Role MCP Read-Only Section (was blocker)
expected: In the same MCP tab, you should see a separate read-only section for role-scoped MCP connections. Each entry shows name, URL, tool count, and a "(Role)" badge. These are read-only. (Previously failed because admin MCP creation didn't set source field.)
result: pass

### 3. Personal MCP Gating When Disabled (was blocker)
expected: If personalMcpEnabled is false on the user's role, the personal MCP section shows a disabled/informational message instead of the "Add Connection" button. No personal MCP actions are available. (Previously failed because /api/auth/me didn't return role data.)
result: pass

### 4. Personal MCP 403 Error Toast (was major)
expected: When personalMcpEnabled is disabled and user attempts to create a personal MCP, a descriptive error toast appears indicating personal MCP connections are not allowed for their role. (Previously failed silently.)
result: pass

### 5. Edit MCP Dialog Pre-population (was major)
expected: In Org Admin > MCP management, clicking edit on an existing MCP connection opens the edit dialog with name, server URL, and auth type pre-populated from the existing connection data. (Previously showed placeholder text instead of saved values.)
result: pass

### 6. MCP Tool Source Labels in Chat Timeline
expected: When an MCP tool is invoked during chat, org-wide MCP tool calls display "(Org)" label and role-scoped MCP tool calls display "(Role)" label in the chat timeline. Personal MCP tools show no special label.
result: pass

### 7. Auto-Include Org/Role MCPs in Chat
expected: Org-wide and role-scoped MCP tools are available in chat without manual activation. The AI can use tools from org/role MCP servers automatically.
result: pass
