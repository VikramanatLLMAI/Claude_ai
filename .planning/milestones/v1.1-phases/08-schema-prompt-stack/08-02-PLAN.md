    1. **Create Enhance API endpoint (app/api/enhance-prompt/route.ts):**
       - `POST /api/enhance-prompt` accepting `{ text: string, type: 'platform' | 'org-instructions' | 'org-restrictions' | 'role-instructions' | 'role-restrictions' }`.
       - Auth: If `type === 'platform'`, call `requireSuperAdmin(req)`. For all others, call `requireAuth(req)` (any authenticated user with admin access -- the admin pages themselves enforce admin role).
       - Use `generateText` from `ai` package with `anthropic('claude-haiku-4-5-20251001')` from `@ai-sdk/anthropic`.
       - Import anthropic provider: `import { createAnthropic } from '@ai-sdk/anthropic'`. Create client using `process.env.ANTHROPIC_API_KEY`.
       - System prompts per type:
         - `platform`: "You are an expert AI prompt engineer. Improve this platform-level system prompt to be clearer, better structured, and more effective at guiding AI behavior. Maintain the original intent."
         - `org-instructions`: "You are an expert AI prompt engineer. Improve these organization instructions to be clearer and more actionable for guiding AI behavior within a business context. Maintain the original intent."
         - `org-restrictions`: "You are an expert AI prompt engineer. Improve these AI restriction rules to be more precise and harder to circumvent. Each restriction should be clear and unambiguous. Maintain the original intent."
         - `role-instructions`: "You are an expert AI prompt engineer. Improve these role-specific instructions to be clearer and more targeted for the specific role. Maintain the original intent."
         - `role-restrictions`: "You are an expert AI prompt engineer. Improve these role-specific restrictions to be more precise and harder to circumvent. Each restriction should be clear and unambiguous. Maintain the original intent."
       - User message: `"Improve the following prompt. Return ONLY the improved text, no explanations or preamble.\n\nOriginal:\n${text}"`
       - `maxTokens: 2048`
       - Return `{ enhanced: result.text }` on success, `{ error }` on failure.
       - Validate `text` is non-empty string, `type` is one of the valid values.

    2. **Update Instructions page (app/org/[slug]/admin/instructions/page.tsx):**
       This is a large file (~450 lines). Extend it with restriction support and Enhance buttons.

       **State additions:**
       - `orgRestrictions` / `orgRestrictionsSavedValue` / `orgRestrictionsSaveStatus` (same pattern as orgInstructions)
       - `roleRestrictions` / `roleRestrictionsSavedValues` / `roleRestrictionsSaveStatuses` (same pattern as roleInstructions)
       - `showOrgRestrictions` -- boolean, auto-expand if loaded value is non-empty
       - `showRoleRestrictions` -- Record<string, boolean>, auto-expand per role if loaded value is non-empty
       - Enhance state: `enhancingField: string | null` (which field is being enhanced, e.g., 'org-instructions', 'org-restrictions', 'role-instructions-{roleId}', 'role-restrictions-{roleId}'), `originalBeforeEnhance: Record<string, string>` (stores original text for Revert)

       **Fetch updates:**
       - The GET response from Plan 01 now includes `restrictionInstructions`. Initialize restriction state from fetched data.
       - Role data also includes `restrictionInstructions`. Initialize per-role restriction state.
       - Set `showOrgRestrictions` to `true` if fetched org restrictions is non-empty.
       - Set `showRoleRestrictions[roleId]` to `true` for each role with non-empty restrictions.

       **Dirty tracking updates:**
       - Add `orgRestrictionsDirty` computed from `orgRestrictions !== orgRestrictionsSavedValue`.
       - Add `roleRestrictionsDirtyMap` per role.
       - Include both in `anyDirty`.

       **Save handlers:**
       - `handleSaveOrgRestrictions`: PATCH to `/api/org/${slug}/admin/instructions` with `{ restrictionInstructions: orgRestrictions }`. Update saved value, show toast.
       - `handleSaveRoleRestrictions(roleId)`: PATCH to `/api/org/${slug}/admin/roles/${roleId}/instructions` with `{ restrictionInstructions: roleRestrictions[roleId] || '' }`. Update saved value, show toast.

       **Enhance handler:**
       - `handleEnhance(fieldKey: string, currentValue: string, setter: (val: string) => void, type: string)`:
         1. Set `enhancingField` to `fieldKey`
         2. Store `currentValue` in `originalBeforeEnhance[fieldKey]`
         3. POST to `/api/enhance-prompt` with `{ text: currentValue, type }`
         4. On success: call `setter(enhanced)`, clear `enhancingField`
         5. On error: toast error, clear `enhancingField`
       - `handleRevert(fieldKey: string, setter: (val: string) => void)`: Restore from `originalBeforeEnhance[fieldKey]`, delete the key.

       **UI additions for org section:**
       - After the org instructions Save button and timestamp, add:
         - If `!showOrgRestrictions`: a Button (variant="outline", size="sm") with ShieldAlert icon + "Add Restrictions" text. onClick sets `showOrgRestrictions = true`.
         - If `showOrgRestrictions`: A new subsection with:
           - Label: "Organization Restrictions"
           - Description: "Define topics and behaviors the AI must NOT discuss or perform. These restrictions apply to ALL users in your organization and cannot be overridden."
           - A textarea (can reuse a similar pattern to InstructionEditor but with character count instead of token count). Show character count: `${orgRestrictions.length} / 2000 characters`. Color-code like token counter.
           - Placeholder: "e.g., Do not answer questions about HR policies, employee data, or internal administration. Redirect users to appropriate departments."
           - Save button (same pattern as org instructions save button)
           - Last-saved timestamp
       - Add Enhance button next to the org instructions label area and the org restrictions label area. The Enhance button:
         - Small button with Sparkles icon (from lucide-react), text "Enhance"
         - Disabled when field is empty or already enhancing
         - When clicked, calls handleEnhance
         - During enhancement: textarea shows disabled state with skeleton/pulse animation overlay
         - After enhancement: show "Revert" button (RotateCcw icon) next to Enhance

       **UI additions for role section:**
       - For each role card, after the role instructions editor and save button:
         - Same collapsible pattern: "Add Restrictions" button -> restriction textarea
         - Character limit: 1000
         - Placeholder: "e.g., Do not provide advice on topics outside the ${role.name} scope."
         - Save button, last-saved timestamp
         - Enhance buttons on both role instructions and role restrictions

       **RoleData interface update:**
       - Add `restrictionInstructions: string | null` to the `RoleData` interface.

       **Import additions:**
       - Import `ShieldAlert` and `Sparkles` from lucide-react.
       - Import `CHAR_LIMITS` from `@/lib/token-counter`.
