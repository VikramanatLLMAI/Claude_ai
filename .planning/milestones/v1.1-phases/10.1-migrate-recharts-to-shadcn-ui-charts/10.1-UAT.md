## UI/UX Improvements (SaaS-Ready)

### High Priority
- **No dark mode toggle**: Neither Super Admin nor Org Admin dashboards have a theme toggle. Users cannot switch between light/dark mode without browser-level overrides.
- **No Super Admin export**: Super Admin analytics has zero export buttons. Org Admin has export on all 12 charts. Platform admins need export for reporting and compliance.
- **Heatmap not responsive**: Peak Usage Hours clips hours 21-23 requiring horizontal scroll. All 24 hours should fit within the card width without scrolling.
- **Empty state charts oversized**: API Key Consumption, MCP Tool Usage empty states take excessive vertical space. Should collapse or shrink when no data.

### Medium Priority
- **Summary cards lack trends**: The 4 summary cards (Total Orgs, Users, Conversations, Tokens) show static numbers with no period-over-period change indicators (e.g., "+5% vs last 30d").
- **Export button has no tooltip**: Icon-only export buttons have accessible name "Export as CSV" for screen readers but no visible hover tooltip for sighted users.
- **Single data point UX**: When only 1 day of data exists, area charts appear nearly empty. Consider showing a bar chart fallback, annotation label, or zero-padded neighbor point.
- **Top Users chart height**: Bar chart fills full card height for a single user entry, wasting vertical space. Should scale height proportionally to entry count.

### Low Priority
- **Tooltip date headers**: Time-series chart tooltips should show the date as header (e.g., "Mar 5, 2026") not the series name (e.g., "Input").
- **Heatmap tooltip styling**: Peak Usage Hours uses native browser `title` tooltips instead of styled Radix UI Tooltip, inconsistent with other charts.
- **Chart title consistency**: Some charts have description text below the title, others don't. Standardize across all chart cards.
- **Error chart colors hardcoded**: ERROR_COLORS and INVITATION_COLORS use hex values (#ef4444, #f59e0b) not CSS variables. Cannot be overridden by org themes.
- **API Key label truncation**: API Key Usage chart truncates labels to "Platform Key (shar...)". Increase axis width or use text wrapping.
