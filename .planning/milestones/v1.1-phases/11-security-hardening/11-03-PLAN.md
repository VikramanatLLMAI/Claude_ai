<task type="auto">
  <name>Task 2: Clean up TypeScript as any casts in API routes</name>
  <files>Multiple files across app/api/ (11 files with 28 casts per research audit)</files>
  <action>
Review all `as any` casts in API route files and replace with specific types.

First, find all casts:
```bash
grep -rn "as any" app/api/ --include="*.ts"
```

Apply these resolution strategies by category:

**Category 1: tenantDb model access (~12 casts)**
For casts like `(tenantDb.usageRecord as any).aggregate(...)`:
- Replace with `(tenantDb.usageRecord as typeof prisma.usageRecord).aggregate(...)`
- Import prisma from `@/lib/db` if not already imported
- Add a single comment at first occurrence: `// Cast required: Prisma $extends loses model types in tenantPrisma()`

**Category 2: Prisma Json fields (~8 casts)**
For casts on `parts`, `metadata`, `availableTools` fields:
- These are `InputJsonValue` type issues when passing to Prisma `.create()` or `.update()`
- Replace `as any` with `as Prisma.InputJsonValue` (import `Prisma` from `@/lib/generated/prisma/client`)
- For reading Json fields: cast to the expected shape, e.g., `as { field: string }[]`

**Category 3: AI SDK type gaps (~5 casts)**
For casts on streamText usage/result objects:
- Define specific interfaces for the expected shape
- Replace `as any` with the specific interface
- If the exact type is unknowable (SDK internal), use `as unknown as SpecificType` pattern

**Category 4: groupBy/aggregate results (~2 casts)**
For Prisma aggregate/groupBy results:
- Define result interfaces inline or at module level:
```typescript
interface UsageAggregate {
  _sum: { inputTokens: number | null; outputTokens: number | null; thinkingTokens: number | null; cacheTokens: number | null };
}
```
- Replace `as any` with the defined interface

**Category 5: Preferences Json (~1 cast)**
- Replace with `as Prisma.InputJsonValue`

For any casts that truly cannot be replaced (genuine type system limitation), keep them but:
1. Change to `as unknown as SpecificType` if possible
2. Add comment: `// Required cast: [brief reason]`

After cleanup, verify remaining count:
```bash
grep -rn "as any" app/api/ --include="*.ts" | wc -l
```

Target: reduce from 28 to fewer than 5, with all remaining documented.
  </action>
