5. **Add "Revoke all other sessions" bulk action:** After the "Active Sessions" heading section (around line 1407), add a "Revoke all other sessions" button that appears when there are 2+ sessions. The button should:
   - Be placed in the header row, right-aligned next to the heading
   - Use `variant="outline"` `size="sm"` styling with destructive text color
   - Call a new `handleRevokeAllOtherSessions` function that iterates through all non-current sessions and revokes each one via the existing `handleRevokeSession` function (or directly calls DELETE on each session endpoint)
   - Show a loading state while revoking
   - After completion, reload sessions

   Add the handler:
   ```typescript
   const [revokingAll, setRevokingAll] = useState(false)

   const handleRevokeAllOtherSessions = async () => {
     const otherSessions = sessions.filter(s => !s.isCurrent)
     if (otherSessions.length === 0) return
     setRevokingAll(true)
     try {
       await Promise.all(
         otherSessions.map(s =>
           fetch(`/api/org/${orgSlug}/sessions/${s.id}`, {
             method: "DELETE",
             headers: getAuthHeaders(),
           })
         )
       )
       setSessions(prev => prev.filter(s => s.isCurrent))
     } catch (error) {
       console.error("Error revoking sessions:", error)
     } finally {
       setRevokingAll(false)
     }
   }
   ```
