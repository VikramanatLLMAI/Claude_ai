<task type="auto">
  <name>Task 2: Add sidebar collapse and profile expander to AdminSidebar</name>
  <files>components/admin/admin-sidebar.tsx</files>
  <action>
Modify the existing `AdminSidebar` component to enable collapsible icon mode and add profile expanders.

**1. Enable collapse mode:**
Change `<Sidebar>` to `<Sidebar collapsible="icon">`. This activates all built-in collapse behavior in sidebar.tsx (width transitions, icon-only mode, group label hiding).

**2. Add custom collapse trigger in SidebarHeader:**
Replace the current SidebarHeader content with a layout that includes a collapse button:
- Keep the existing icon (Building2 for org, Shield for super admin) and title/subtitle
- Add the title/subtitle div with `group-data-[collapsible=icon]:hidden` so text hides when collapsed
- Add a custom collapse button using `useSidebar().toggleSidebar()` with a ChevronLeft icon (per user decision -- NOT the default PanelLeft icon from SidebarTrigger)
- The ChevronLeft rotates 180 degrees when sidebar is collapsed: `cn("h-4 w-4 transition-transform duration-200", state === "collapsed" && "rotate-180")`
- Button uses `variant="ghost"` with `className="ml-auto h-7 w-7 shrink-0"` and proper aria-label
- In collapsed mode, position the button centered: `group-data-[collapsible=icon]:ml-0`

**3. Replace SidebarFooter with profile expander:**
Remove the current bare footer (user info + Back to Chat button + Sign Out button). Replace with a Radix Collapsible-based profile expander:

For BOTH variants:
- Import `Collapsible, CollapsibleTrigger, CollapsibleContent` from `@/components/ui/collapsible`
- SidebarFooter with `border-t border-sidebar-border p-2`
- Inside: `SidebarMenu > SidebarMenuItem > Collapsible`
- CollapsibleTrigger wraps a SidebarMenuButton with `size="lg"` and `tooltip={currentUser?.name || "Account"}`
- Trigger shows: avatar circle (initial letter in `h-8 w-8 rounded-full bg-sidebar-accent`), truncated name, ChevronUp icon
- Name and ChevronUp get `group-data-[collapsible=icon]:hidden` (not visible in collapsed mode)
- CollapsibleContent gets `group-data-[collapsible=icon]:hidden`
- Content shows: email (truncated, text-xs text-muted-foreground), then action buttons

For Org Admin variant (isOrgAdmin && orgSlug):
- "Back to Chat" link (`ArrowLeft` icon, navigates to `/org/${orgSlug}/chat`)
- "Log Out" button (destructive text color)

For Super Admin variant:
- "Log Out" button only (no Back to Chat -- Super Admins have no chat context)

Action buttons use: `variant="ghost" size="sm" className="w-full justify-start h-8 text-sm"`

**4. Import updates:**
Add imports for: `ChevronLeft`, `ChevronUp` from lucide-react; `Collapsible`, `CollapsibleTrigger`, `CollapsibleContent` from collapsible.tsx; `useSidebar` from sidebar.tsx.

**Important:** Do NOT add a Settings link to the profile expander -- the user decision says Settings is accessed via the chat interface, not the admin sidebar.
