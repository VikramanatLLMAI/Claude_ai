Create `.github/workflows/ci.yml` with two jobs:

**Job 1: `unit-and-lint`** (runs on every push to any branch):
- runs-on: ubuntu-latest
- timeout-minutes: 10
- Steps:
  1. `actions/checkout@v5`
  2. `actions/setup-node@v5` with node-version 20 and cache npm
  3. `npm ci`
  4. `npm run lint` (lint step)
  5. `npm run test:run` (unit tests, using the Vitest single-run command)
- Environment variables for unit tests:
  - `KEY_ENCRYPTION_SECRET: '0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef'`

**Job 2: `e2e`** (runs only on pull_request to main):
- if: `github.event_name == 'pull_request'`
- runs-on: ubuntu-latest
- timeout-minutes: 30
- services:
  - postgres (image postgres:16, env POSTGRES_USER/PASSWORD/DB, port 5432, health check)
- Steps:
  1. `actions/checkout@v5`
  2. `actions/setup-node@v5` with node-version 20 and cache npm
  3. `npm ci`
  4. `npx playwright install --with-deps chromium`
  5. Setup database: `npm run db:push && npm run db:seed -- --dev`
  6. `npx playwright test`
  7. Upload playwright traces on failure: `actions/upload-artifact@v4` with path `test-results/`, retention 7 days, `if: failure()`
- Environment variables:
  - `DATABASE_URL: postgres://postgres:postgres@localhost:5432/test_db`

  - `NODE_ENV: development` (for path-based routing in E2E)
